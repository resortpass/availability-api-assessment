# Interviewer-Only Material

**Delete this entire `rubric/` directory before sharing the repo with a candidate.** Nothing in here should ever be candidate-visible.

- `MAINTAINER.md` — how to run the 60-minute session: setup checklist, pacing, failure simulation, discussion questions.
- `HINTS.md` — verbal nudges for stuck candidates, each with when-to-give guidance.
- `EVALUATION_RUBRIC.md` — evaluation guide: green/yellow/red flags for the live format (integration design, response consistency, error handling, collaboration — not schema design, which is provided).
- `FOLLOWUPS.md` — extension prompts for early finishers, deeper discussion, or later rounds.
- `example-response-two.json` — sample second-vendor payload; hand to the candidate only when posing FOLLOWUPS.md's second-vendor prompt.
