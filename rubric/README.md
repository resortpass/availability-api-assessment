# Interviewer-Only Material

**Delete this entire `rubric/` directory before sharing the repo with a candidate.** Nothing in here should ever be candidate-visible.

This directory contains everything an interviewer needs to run the live availability-API exercise: `MAINTAINER.md` explains how to set up and facilitate the 60-minute session (pre-session checklist, pacing, checkpoints, discussion questions, and the deliberate dirty-data wrinkle in the mock API); `HINTS.md` is a set of verbal nudges to give when a candidate gets stuck, each with guidance on when to deliver it; `EVALUATION_RUBRIC.md` is the scoring guide, weighted for the live format — integration design, response consistency, error handling, and collaboration signals rather than schema design (the schema is provided).
